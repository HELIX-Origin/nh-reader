## ⚠️ nhentai.net outages

NH Reader is an independent client. If the nhentai.net website or API is unavailable, the app
cannot load content. Check the site directly before opening an issue.

## 🔒 Security

For security vulnerabilities, **do not** open a public issue — follow [SECURITY.md](./SECURITY.md).

Before opening an issue, please search existing issues and discussions — your question may already
be answered.
