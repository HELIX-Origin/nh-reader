Browse and sort galleries, search with advanced filters, keep a persistent blacklist, read in a fast reader, download archives, and keep everything in a private local-first database.

## Install

Download the installer for your platform from [GitHub Releases](https://github.com/HELIX-Origin/nh-reader/releases) (Windows `.exe` / `.msi`, macOS `.dmg`, Linux `.deb` / `.AppImage`). See the [installation guide](docs/user/installation.md).

## Run from source

```bash
npm install
npm run tauri:dev
```

Prerequisites: [Node.js](https://nodejs.org/) LTS and [Rust](https://www.rust-lang.org/) stable. Quality gate: `npm run verify`. Details in the [development setup guide](docs/developer/development-setup.md).
