# Privacy & Data Security

NH Reader is built with an absolute commitment to user privacy, local autonomy, and transparency.

---

## Zero Telemetry Policy

- **No Analytics**: NH Reader contains zero telemetry SDKs, analytics tracking beacons, crash report uploaders, or user tracking scripts.
- **No Third-Party Advertising**: There are no ads, promotional banners, sponsored suggestions, or marketing trackers embedded in the application.
- **Direct Communication Only**: Network calls originate exclusively from the local Rust backend directly to the user-requested target host (`nhentai.net` and its content distribution subdomains `i.nhentai.net` / `t.nhentai.net`). No intermediary proxy, analytics server, or telemetry collector is ever contacted.

---

## Local Data Storage

All user configurations, preferences, bookmarks, history, and cached media are stored locally on your own filesystem:

### Database Storage
All metadata is maintained in a local SQLite database file:
- **Windows**: `%LOCALAPPDATA%\club.helix-origin.nh-reader\data.db`
- **macOS**: `~/Library/Application Support/club.helix-origin.nh-reader/data.db`
- **Linux**: `~/.local/share/club.helix-origin.nh-reader/data.db`

This database contains:
- Bookmarked galleries (Favorites)
- Reading history and page progress positions
- Global blacklist rules and categories
- User preferences and UI state (theme, scale, reading modes)
- Optional session cookies (`sessionid`, `cf_clearance`)

### Disk Cache Storage
Images and thumbnails are temporarily cached in an isolated cache directory:
- **Windows**: `%LOCALAPPDATA%\club.helix-origin.nh-reader\cache\`
- **macOS**: `~/Library/Caches/club.helix-origin.nh-reader/`
- **Linux**: `~/.cache/club.helix-origin.nh-reader/`

---

## Credential Handling

If you configure account session cookies:
- Tokens are stored solely in the local SQLite database.
- Tokens are never logged to console outputs or written to unencrypted debug dumps.
- Disconnecting your account via the interface immediately executes a SQL `DELETE` operation, permanently erasing the credentials.

---

## Purging Your Data

You retain full ownership and control over all data generated by NH Reader:

1. **In-App Purge**: Navigate to **Settings** > **Privacy** and select:
   - **Clear Image Cache**: Purges temporary disk cache files.
   - **Clear History**: Erases all browsing and reading history.
   - **Reset App**: Resets database tables back to factory initial state.
2. **Manual Cleanup**: Completely deleting the application directory (`club.helix-origin.nh-reader`) permanently wipes all saved data from your machine.
